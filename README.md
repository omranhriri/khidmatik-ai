# خدمتك AI — إصدار الإنتاج الأول

## ما تم تنفيذه
- قاعدة بيانات SQLite للطلبات.
- API لإنشاء الطلبات ومتابعتها.
- لوحة إدارة محمية باسم مستخدم وكلمة مرور من متغيرات البيئة.
- تغيير حالة الطلبات.
- صفحة العميل وصفحة الإدارة.

## تشغيل
1. ثبّت Node.js.
2. شغّل: `npm install`
3. عيّن:
   - `ADMIN_USER`
   - `ADMIN_PASSWORD`
   - `SESSION_SECRET`
4. شغّل: `npm start`

## ملاحظات قبل الإطلاق التجاري
- استخدم كلمة مرور قوية ولا تترك القيم الافتراضية.
- استخدم HTTPS عبر الاستضافة.
- اربط بوابة دفع مناسبة للأردن بعد التحقق من شروطها.
- لا تضع أسرار الدفع أو مفاتيح قواعد البيانات داخل ملفات المتصفح.
